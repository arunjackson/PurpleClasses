# 1:1 AI Classes for Kids - website

A standalone landing page for 1:1 live AI classes for kids (ages 8-12).
Plain HTML and CSS - no build step, no dependencies, works anywhere.

## Files

- `index.html` - the whole page
- `styles.css` - the styling
- `assets/purple-hero.png` - Purple the mascot, hero image
- `assets/purple-poses.png` - Purple in four poses

## View it locally

Just open `index.html` in any browser (double-click it).

Or serve the folder:

```
python3 -m http.server 8000
```

then visit http://localhost:8000

## Put it online

Any static host works. For example:

- GitHub Pages: push these files to a repo, then Settings > Pages > deploy from branch
- Netlify / Vercel: drag this folder onto their dashboard, or connect the repo
